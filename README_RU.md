# Visual-Monitoring-of-WinCC-Redundancy-Status
Визуальный контроль состояния резервирования серверов WinCC 7.5

В системах WinCC с резервированием два сервера обеспечивают отказоустойчивость системы. Однако наличие резервирования не означает, что оба сервера постоянно находятся в исправном состоянии.
Например, один сервер может выйти из строя, а второй продолжит работать в штатном режиме. Для оператора это может остаться незаметным, хотя система уже работает без резервирования.
WinCC предоставляет внутренние системные переменные, позволяющие определить состояние серверов, их роли и состояние синхронизации. Но постоянная проверка этих переменных через диагностические списки неудобна.
Для решения этой задачи была разработана отдельная диагностическая мнемосхема, объединяющая основные параметры резервирования в одном окне.

На экране отображаются:

* состояние обоих серверов;
* текущая роль серверов;
* состояние связи;
* состояние синхронизации;

Это позволяет быстро определить, действительно ли резервирование готово к работе, без поиска информации по отдельным системным переменным.
Решение предназначено прежде всего для существующих систем WinCC/PCS 7, где подобный диагностический экран изначально не был предусмотрен. В некоторых проектах WinCC такая информация уже отображается штатными или автоматически создаваемыми средствами.
Система резервирования при этом не изменяется. Используются существующие внутренние переменные WinCC, а разработанный экран предоставляет более удобный способ контроля их состояния.
